# Asset licences and provenance

Every byte shipped inside **Mumbai: The Island City** was produced for this project.
Nothing is imported from another game, ripped from a commercial product, downloaded
from an asset store, or derived from a mapping service.

---

## 1. What is in the APK

| Asset | Origin | Licence |
|---|---|---|
| `assets/world/*.mwl` — land use, elevation, roads, rail, districts, landmarks, airports, chunk index | Generated by `tools/build_world.py` from hand-authored coordinates in `tools/mumbai_geo.py` | Project source, same licence as the repository |
| All 3D geometry (terrain, buildings, roads, bridges, vegetation, props) | Generated at runtime by `core/.../world/ChunkBuilder.java` from the packaged rasters | Project source |
| All vehicles, boats, aircraft and the player character | Generated by `core/.../world/ProtoMeshes.java` — boxes, wedges, tapered tubes and cylinders assembled in code | Project source |
| Shaders | `android/.../Shaders.java`, written for this project | Project source |
| HUD, instruments, minimap, touch controls | Drawn with `android.graphics.Canvas` primitives in `HudView` / `TouchController` | Project source |
| Fonts | The device's built-in monospace typeface via `Typeface.MONOSPACE` | Supplied by the OS; nothing bundled |
| Audio | **None.** The build ships no audio files | — |

There are **no** bitmap textures, no `.obj`/`.fbx`/`.gltf` imports, no sprite sheets,
no music and no sound effects in the APK. The only non-code assets are the five
binary world layers listed above.

## 2. Vehicles: deliberately fictional

Every vehicle is an unbranded, generic shape:

* no manufacturer names, logos, badges, grille shapes or model names
* no real registration plates, fleet numbers or operator liveries
* no reproduction of any specific vehicle's styling

The autorickshaw, bus, truck, hatchback, sedan, taxi and motorcycle are built from the
same primitive helpers and differ only in dimensions and flat colours chosen in
`ProtoMeshes`. The aircraft are a generic single-engine trainer and a generic twin-jet
airliner silhouette. The boats are a generic launch, a generic planing speedboat and a
generic harbour ferry.

The taxi uses a dark body with a light roof. That is a functional two-tone scheme, not
a reproduction of any operator's trade dress, and carries no markings.

## 3. Places and names

Place names used in the game (Dadar, Bandra, Dharavi, Colaba, Vasai Creek, Thane
Creek, Trombay, Kanheri, and so on) are **geographic names in ordinary public use**.
They are not trademarks of the project and are used descriptively to identify real
locations, the same way any atlas or signpost does.

Named landmarks are rendered as **generic massing at public-map level of detail**.
No landmark is modelled from architectural drawings, photogrammetry or any
copyrighted 3D model. Where a structure is itself protected (for example a
contemporary building's design), only an abstract block form of the correct
approximate footprint and height is drawn.

The following are deliberately **not** depicted in detail, consistent with the
project's safety rules: airport airside layouts beyond runway geometry and generic
terminal massing, port security arrangements, naval and defence establishments
(Navy Nagar appears as ordinary built-up coastline), and any government facility's
internal layout. Everything is exterior, public-map level, and no operationally
sensitive detail is included.

## 4. What is explicitly not used

* No Grand Theft Auto or any Rockstar asset, name, code, mechanic implementation or
  visual style reference.
* No Google Maps, Google Earth, Street View, Apple Maps, Bing, Mapbox or HERE data,
  imagery, tiles, elevation or 3D meshes.
* No OpenStreetMap geometry. (See `DATA_SOURCES.md` §1 — because none is used, no OSM
  attribution is displayed. If you enable `tools/osm_import.py` yourself, you become
  responsible for the ODbL attribution requirement.)
* No SRTM, ASTER, Copernicus, Bhuvan or other elevation product.
* No commercial or free asset-store models, textures, HDRIs or audio.
* No third-party game engine. The renderer and physics are written for this project;
  see `docs/TECH_STACK_DECISIONS.md`.
